# CallUp
A full-stack communication platform that enables users to seamlessly connect through real-time calling features with a modern and intuitive user interface.

Overview

CallUp is a full-stack web application designed to provide a smooth and reliable calling experience between users.
It integrates a responsive frontend with a scalable backend architecture to ensure efficient communication and real-time interaction.

The project demonstrates practical implementation of:

Frontend-Backend Integration

REST API Communication

Authentication & User Management

Real-Time Communication Logic

Modular Scalable Architecture

Installation & Setup
1. Clone the Repository

git clone https://github.com/joyita-bhattacharjee/CallUp.git

cd CallUp

2. Setup Backend

cd backend
npm install
npm start

3. Setup Frontend

cd frontend
npm install
npm start

Environment Variables

Create a .env file inside the backend folder and add:

PORT=your_port_number
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
